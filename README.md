## О клипе

Клип построен строго по смыслу песни. Герой идёт от демонического ночного города
сквозь серую рутину и TV-помехи — к золотому рассвету. Мир вокруг не меняется.
Меняется канал, по которому он его смотрит.

| Акт | Тайминг | Смысл |
|---|---|---|
| Интро | 0:00–0:20 | Тёмный город, шёпот, дрон — «не всё зависит от мышления…» |
| Куплет 1 | 0:20–0:50 | Серое утро, толпа, винящие обстоятельства vs ищущие возможности |
| Пре-дроп | 0:50–1:00 | «Тот же город. Тот же свет.» — один кадр до/после перемены взгляда |

## Сайт (GitHub Pages)

Страница клипа — интерактивный телевизор **DIRTYGEN·ТВ**:

- 📺 CRT-плеер с развёрткой и глитч-титрами
- 🎚 живой визуализатор звука (Web Audio API)
- 🎯 синхронный текст песни — строки подсвечиваются в такт клипу
- 🗺 главы и сцены с перемоткой по клику
- 🌓 кнопка **«СМЕНИ КАНАЛ»** (или клавиша `K`) — переключает тему
  сайта **тьма ↔ рассвет** через вспышку TV-помех — как арка клипа
- ⌨️ `Space` — пауза, `←/→` — ±5 сек

## ⚠️ Важно: демо-звук

В клипе сейчас стоит **временный демо-саундтрек** (тёмный эмбиент + 808-бас,
синтезирован под структуру песни: дроны → грув → дропы → рассвет).
Чтобы поставить **оригинальную песню**, положи свой файл (например `song.wav`)
и пересобери одной командой:

```bash
# 1) подменить аудио в клипе (тайминги сохранятся)
ffmpeg -i video/ya_ne_v_seti_clip.mp4 -i song.wav \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k \
  -shortest video/ya_ne_v_seti_clip_final.mp4

# 2) обновить MP3 для сайта
ffmpeg -i song.wav -b:a 192k audio/soundtrack_demo.mp3
```

Если оригинал длиннее/короче 3:07 — правь тайминги секций в `tools/build_video.py`
(массив `SCENES`) и запусти `python3 tools/build_video.py render && python3 tools/build_video.py final`.

## Пересборка клипа с нуля

```bash
bash tools/gen_frames.sh 1 28            # 28 AI-кадров
python3 tools/postprocess_frames.py      # кроп 16:9, 4K-апскейл, веб-миниатюры
python3 tools/make_soundtrack.py         # демо-саундтрек 187 c
python3 tools/build_video.py render      # сегменты (Ken Burns, помехи, титры)
python3 tools/build_video.py final       # склейка + аудио
```

Требования: `ffmpeg`, `python3 + Pillow + numpy`, доступ к генератору изображений z-ai.

**[Интро]**
— Замечал, что одни постоянно жалуются на жизнь?
— А другие? — Другие тоже. Просто не тратят на это всё время.
— То есть всё зависит от мышления?
— Не совсем. Ещё от того, что ты с ним делаешь.

Кто-то ищет другие возможности.
Можно годами доказывать всем,
Что вокруг виноваты не те и не те.

Не всё в этом мире зависит от нас.

**[Куплет 2]**
