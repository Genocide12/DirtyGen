## Клипы и их смысл

Все три клипа собраны из 28 AI-кадров (одна вселенная: ночной мегаполис →
серая рутина → стена кинескопов → выбор → золотой рассвет), но у каждого —
свой тайминг, порядок сцен и грейд. Сцены подогнаны под **реальную энергию
треков** (анализ RMS): дропы, брейки и пики попадают в кадр.

| Клип | Трек | Длина | Особенности |
|---|---|---|---|
| «Я не в сети» | `Трек .mp3` | 3:05.6 | дроп на 0:52 · брейк 1:58 · главный пик 2:48 · титры на затухании |
| «Трек 2» | `Трек2.mp3` | 3:34 | неоновый грейд, дроп на 1:20, взрыв на 3:18 |
| «Трек 3» | `Трек3.mp3` | 4:19 | большой брейк 2:16, стробоскоп-финал 3:44–4:16 |

## Структура репозитория

```
├── index.html              # сайт-телевизор (5 каналов)
├── assets/
│   ├── css/style.css       # помехи, CRT, глитч, темы
│   ├── js/main.js          # смена каналов, OSD, лирика, видео
│   ├── img/                # обложка, портрет, OG, постеры
│   └── frames_web/         # веб-миниатюры сцен
├── video/                  # 3 клипа MP4 1080p
│   ├── ya_ne_v_seti_clip.mp4
│   ├── trek2_clip.mp4
│   └── trek3_clip.mp4
├── audio/                  # оригинальные треки (mp3)
├── frames/                 # 28 исходных AI-кадров 1344×768
└── tools/                  # скрипты сборки
    ├── gen_frames.sh           # генерация кадров
    ├── gen_site_images.sh      # обложка/портрет/OG
    ├── postprocess_frames.py   # кроп 16:9 + 4K + веб-миниатюры
    ├── analyze_track.py        # анализ энергии трека (RMS-профиль)
    └── build_clip.py           # сборка всех 3 клипов (тайминги в конфигах)
```

## Пересборка клипа

```bash
python3 tools/analyze_track.py "путь/к/треку.mp3"   # посмотреть структуру
python3 tools/build_clip.py clip1 render            # сегменты (кэшируются)
python3 tools/build_clip.py clip1 final             # склейка + трек
```

Тайминги секций каждого клипа — в конфигах `CONFIGS` внутри `tools/build_clip.py`.
Сегменты кэшируются: при правке одного тайминга перерендерятся только изменённые.
