**Смотреть:** https://genocide12.github.io/DirtyGen/

Клип на трек **«Смени канал»** — три канала, три версии звука, одна история.
Артист — **Грязный Гена** (Dirty G, DIRTYGEN).

| Канал | Версия | Длина |
|---|---|---|
| CH 01 | «Смени канал» — основная | 3:06 |
| CH 02 | «Смени канал» · NIGHT — ночная | 3:34 |
| CH 03 | «Смени канал» · DAWN — с рассветом | 4:19 |

Плюс страница артиста: имя, девиз проекта и ссылки на соцсети.
Переключение каналов — через вспышку помех: колесо мыши, свайп или стрелки.

## Как смотреть

- **колесо / свайп / ← →** — переключение каналов;
- **клик по DIRTYGEN** в шапке — сразу страница артиста;
- **клик по номеру канала** (CH 01 / 03) — выпадающий список всех страниц;
- **цифры 1–3** — прямой выбор канала, **0** — страница артиста;
- звук включается автоматически при старте.
